# Upgrade guidance

RIGOR has no published stable release yet.

For the development migration to `0.2.0`, read [MIGRATIONS.md](MIGRATIONS.md). A `0.1.0` Research Bundle is structurally incomplete under the current contract until it records the loop policy, registers, and initial iteration.

Before upgrading a future skill, adapter, or implementation, read the release notes, compatibility range, migration notes, and declared provenance. Run the repository validator and applicable behavioral evaluations. Do not overwrite user-authored investigation records or evidence ledgers.
