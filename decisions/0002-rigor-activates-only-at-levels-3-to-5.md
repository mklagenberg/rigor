# 0002 — RIGOR activates only at Levels 3–5

- Status: accepted
- Date: 2026-08-13
- Decision owner: Mauricio M. Klagenberg

## Context

Deep investigation has cost. Applying it to ordinary lookups creates delay, noise, and performative rigor.

## Decision

RIGOR is reserved for Levels 3–5. Levels 0–2 use direct answer, retrieval, or ordinary synthesis unless a documented trigger raises the level.

## Consequences

Every RIGOR run needs a level rationale. Level determines the minimum evidence, challenge, approval, and revalidation controls.

## Alternatives considered

- Always use full deep research: rejected as disproportionate.
- Let each agent decide silently: rejected because it hides the cost/risk trade-off.

## Follow-up

Evaluate level selection with representative cases.
