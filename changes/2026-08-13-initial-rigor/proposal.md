# Establish RIGOR v0.1.0

## Problem

No reusable methodology exists for proportionate, evidence-grounded, multi-workstream investigations that combine deep research, source validation, investigative methods, and revalidation.

## Current contract

The repository was empty.

## Proposed contract

Create RIGOR as a MODA-native methodology with explicit activation levels, process, evidence model, agency boundaries, repository governance, and deterministic validation.

## Alternatives

- A single deep-research prompt: rejected because it cannot preserve durable contracts, auditability, or proportionality.
- A vendor-specific agent: deferred; RIGOR must remain vendor-independent.

## Risks

- Premature precision can create false authority. Mitigation: retain partial conformance and roadmap unimplemented capabilities.
- The method can be over-applied. Mitigation: Levels 0–2 are explicitly out of scope.

## Acceptance criteria

- [x] Normative specification and repository interfaces exist.
- [x] Activation, evidence, source discovery, process, agency, safety, and revalidation are explicit.
- [x] Change control and durable decisions exist.
- [x] Deterministic repository validation is included.

## Compatibility and migration

Initial pre-release capability at `0.1.0`; no adopter migration exists.

## Recovery

Revert the initial commits or supersede individual contracts through a new Change Set and Decision Record.
