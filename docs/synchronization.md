# Synchronization and provenance

RIGOR is designed with MODA `v1.0.0`, compatibility `^1.0.0`, pinned to commit `81171ed22163f73f250e32534f9edc3a4f8d51e1`.

The methodology source, future skill core, host adapters, distribution packages, and installed copies are separate artifacts. Equal version strings do not prove equal content.

On a future RIGOR skill’s first activation, compare installed version, supported RIGOR range, canonical release manifest, and applicable advisories. Report `current`, `update-available`, `security-update-required`, `incompatible`, `unknown`, or `offline`; never silently self-update.
